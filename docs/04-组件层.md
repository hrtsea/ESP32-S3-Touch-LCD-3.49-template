> **硬性约束**：不允许修改 `components/` 目录下任何代码。本目录是 BSP 与第三方库的"封装层"，主应用通过头文件暴露的 API 调用。

**排除编译声明**（[顶层 CMakeLists.txt](../CMakeLists.txt)）：
```cmake
set(EXCLUDE_COMPONENTS audio_bsp codec_board espressif__esp_codec_dev)
```
原因：IDF 5.2.x 上 `esp_codec_dev` 拉入 legacy `driver/i2c.c` 构造器，与新版 `i2c_master` 冲突会触发启动 abort。

## 4.2 SensorLib（传感器库）

来源：Lewis He (lewishe@outlook.com) MIT 开源，vendored 副本。

支持的器件类（覆盖广泛，但本项目实际只用了 **2 个**）：
- **加速度 / IMU**：BMA423 / BHI260AP / QMI8658（实际使用）/ QMC6310 / BMM150 / MPU6886
- **光学**：CM32181 / LTR553
- **RTC**：PCF85063（实际使用）/ PCF8563
- **触摸**：CST816 / CST226 / CST92xx / CSTXXX / GT911 / GT9895 / FT6X36 / CHSC5816
- **IO 扩展**：XL9555
- **电源量测**：BQ27220

> **本项目触摸不走 SensorLib**：3.49" LCD 触摸由 `managed_components/espressif__esp_lcd_axs15231b` + `main/drivers/disp_driver.c` 自行处理。

### 关键 API（实际使用的 2 个类）

```cpp
// SensorPCF85063 (RTC)
bool begin(SensorCommCustom::CustomCallback cb);
void setDateTime(uint16_t y, uint8_t mo, uint8_t d, uint8_t h, uint8_t mi, uint8_t s);
RTC_DateTime getDateTime();

// SensorQMI8658 (IMU)
bool begin(SensorCommCustom::CustomCallback, SensorCommCustomHal::CustomHalCallback, uint8_t addr);
bool selfTestAccel();
bool selfTestGyro();
void configAccelerometer(ACC_RANGE, ACC_ODR, LPF_MODE);   // 项目用 ACC_RANGE_4G / ACC_ODR_1000Hz
void configGyroscope(GYR_RANGE, GYR_ODR, LPF_MODE);        // 项目用 GYR_RANGE_64DPS / GYR_ODR_896_8Hz
bool getAccelerometer(float &x, &y, &z);
bool getGyroscope(float&, float&, float&);
float getTemperature_C();
```

### 与主应用交互

仅通过 [i2c_equipment.cpp](../components/i2c_equipment/i2c_equipment.cpp) 间接调用。`i2c_dev_Callback()` 把 SensorLib 的 `readReg/writeReg` 请求按 I2C 地址路由到 `rtc_dev_handle` / `imu_dev_handle`（来自 `i2c_bsp`）。

## 4.3 adc_bsp（ADC 电池电压）

使用 ESP-IDF `adc_oneshot` v5 驱动 + `adc_cali_curve_fitting` 校准。

配置：`ADC_UNIT_1` / `ADC_CHANNEL_3` / `ADC_ATTEN_DB_12`（满量程 ~3.3V）/ `ADC_BITWIDTH_12`。读取后校准电压 × 3（分压电阻比例）= 系统电压。

```c
void adc_bsp_init(void);
void adc_get_value(float *value, int *data);   // *value=系统电压(V), *data=原始 ADC 码
```

调用方：[hw_init.c](../main/utils/hw_init.c) 第 95 行（`[6/9] ADC battery` 步骤）。

## 4.4 audio_min（精简音频）

轻量 MIDI 风格方波回放，**复用 `radio` 组件的 ES8311 play_dev**（自身不拥有 I2S / codec），避免与 radio 争用同一芯片。

内置固定曲目 `TWINKLE[]`（《小星星》MIDI 序列）。

```c
esp_err_t audio_min_init(void);
void      audio_min_play_midi(bool play);
bool      audio_min_is_playing(void);
void      audio_min_set_volume(uint8_t vol_0_100);   // 软件增益 Q8.8
bool      audio_min_is_available(void);              // radio 不在流式播放时才可用
void      audio_min_shutdown(void);                   // 仅 kill worker 线程
```

调用方：
- [hw_init.c](../main/utils/hw_init.c) 第 99 行：`audio_min_init()` + `audio_min_set_volume(g_cfg.audio_volume)`
- [cli.c](../main/utils/cli.c) `audio_off` 命令：`audio_min_shutdown()`
- UI（旧版 `ui_hello.c` / `ui_settings.c`）：Play/Stop 按钮 + 音量 slider

## 4.5 button_bsp（按键支持）

集成 Zibin Zheng 的 `multi_button` 库（vendored）。配置两个 GPIO 输入：
- `USER_KEY_1 = GPIO0`（BOOT 键），id=1，active=0
- `USER_KEY_2 = GPIO16`，id=2，active=0

启动 5ms 周期 `esp_timer` 调用 `button_ticks()` 推进状态机。通过 FreeRTOS 事件组对外通知：
- `boot_groups`：BOOT 键 bit0 单击 / bit1 双击 / bit2 长按 / bit3 弹起
- `pwr_groups`：GPIO16 bit0 单击 / bit1 长按 / bit2 弹起

```c
extern EventGroupHandle_t boot_groups;
extern EventGroupHandle_t pwr_groups;
void   button_Init(void);
uint8_t user_button_get_repeat_count(void);
uint8_t user_boot_get_repeat_count(void);
```

调用方：[hw_init.c](../main/utils/hw_init.c) 第 108 行（`[9/9] SD card + Buttons`）。

## 4.6 i2c_bsp（I2C 驱动）

ESP-IDF 新版 `i2c_master` 驱动封装。`i2c_master_Init()` 初始化两条总线：

| 总线 | SCL | SDA | 设备 |
|------|-----|-----|------|
| `I2C_NUM_0`（主总线） | `ESP_SCL_NUM=48` | `ESP_SDA_NUM=47` | `rtc_dev_handle` @ 0x51（PCF85063）+ `imu_dev_handle` @ 0x6b（QMI8658） |
| `I2C_NUM_1`（触摸总线） | `Touch_SCL_NUM=18` | `Touch_SDA_NUM=17` | `disp_touch_dev_handle` @ 0x3b（AXS15231B 触摸） |

7-bit 地址，`scl_speed_hz = 300000`。

```c
extern i2c_master_dev_handle_t disp_touch_dev_handle;
extern i2c_master_dev_handle_t rtc_dev_handle;
extern i2c_master_dev_handle_t imu_dev_handle;
extern i2c_master_bus_handle_t esp_i2c_bus_handle;   // = I2C_NUM_0 bus

void    i2c_master_Init(void);
uint8_t i2c_writr_buff(i2c_master_dev_handle_t dev, int reg, uint8_t *buf, uint8_t len);
uint8_t i2c_read_buff(i2c_master_dev_handle_t dev, int reg, uint8_t *buf, uint8_t len);
uint8_t i2c_master_write_read_dev(i2c_master_dev_handle_t dev, uint8_t *w, uint8_t wl, uint8_t *r, uint32_t rl);
uint8_t i2c_master_touch_write_read(i2c_master_dev_handle_t dev, uint8_t *w, uint8_t wl, uint8_t *r, uint32_t rl);
```

`reg == -1` 表示"裸数据"模式（不拼寄存器字节），适配触摸 IC 的多字节读。

调用方：
- [hw_init.c](../main/utils/hw_init.c) 第 62 行（`[1/9] I2C buses`）
- [disp_driver.c](../main/drivers/disp_driver.c) 第 252 行：触摸读取
- i2c_equipment 间接调用（通过 `i2c_writr_buff` / `i2c_read_buff`）

## 4.7 i2c_equipment（RTC + IMU 桥接）

**唯一用 C++ 编写的 BSP 组件**。将 SensorLib 的 `SensorPCF85063` / `SensorQMI8658` 桥接到 `i2c_bsp` 之上，对外以 C ABI 暴露扁平化取值 API。

```c
typedef struct { uint16_t year; uint8_t month, day, hour, minute, second, week; } RtcDateTime_t;
typedef struct { float accx, accy, accz, gyrox, gyroy, gyroz; } ImuDate_t;

void i2c_rtc_setup(void);
void i2c_rtc_setTime(uint16_t y, uint8_t mo, uint8_t d, uint8_t h, uint8_t mi, uint8_t s);
void i2c_rtc_task(void *arg);                  // 5s 周期 printf 时间（demo）
RtcDateTime_t i2c_rtc_get(void);

void i2c_imu_setup(void);
void i2c_imu_task(void *arg);                  // 100ms 周期 printf 加速度/陀螺/温度（demo）
ImuDate_t i2c_imu_get(void);
```

内部桥接逻辑：
- `i2c_dev_Callback(addr, reg, buf, len, writeReg, isWrite)`：按地址路由到 `rtc_dev_handle` / `imu_dev_handle`
- `hal_callback(op, p1, p2)`：GPIO 模式设置 / 写电平 / 读电平 / millis / delay / delayMicroseconds

调用方：
- [hw_init.c](../main/utils/hw_init.c) 第 90-91 行（`[5/9] RTC + IMU`）
- [sntp_manager.c](../main/network/sntp_manager.c) 第 55 行：SNTP 同步成功后回写 RTC

## 4.8 lcd_bl_pwm_bsp（背光 PWM）

基于 `ledc` 的 LCD 背光控制。

- `LEDC_LOW_SPEED_MODE` + `LEDC_TIMER_3` + `LEDC_TIMER_8_BIT`（256 级）+ 50 kHz
- 通道 `LEDC_CHANNEL_1` 绑定到 `EXAMPLE_PIN_NUM_BK_LIGHT`（GPIO8）
- **反向占空比**：`duty` 越大反而越暗（硬件极性反向），调用方按 `0xFF - brightness` 传入

```c
void lcd_bl_pwm_bsp_init(uint16_t duty);
void setUpduty(uint16_t duty);
```

调用方：
- [hw_init.c](../main/utils/hw_init.c) 第 82 行：`lcd_bl_pwm_bsp_init(0xFF - g_cfg.brightness)`
- [ui_helpers.c](../main/ui/ui_helpers.c) 第 102 行：`setUpduty(0xFF - bri)`（UI 设置页改亮度时实时下发）

## 4.9 lvgl（LVGL 8.3.11）

vendored 副本，非项目原创。通过 `env_support/cmake/esp.cmake` 集成到 ESP-IDF 构建。

- `src/core/`：`lv_obj` / `lv_disp` / `lv_indev` / `lv_event` / `lv_group` / `lv_refr` / `lv_theme`
- `src/draw/`：`sw`（纯软件） / `arm2d` / `nxp/pxp` / `sdl`
- `src/widgets/`：arc / bar / btn / btnmatrix / canvas / checkbox / dropdown / img / label / line / roller / slider / switch / table / textarea
- `src/extra/widgets/`：animimg / calendar / chart / colorwheel / imgbtn / keyboard / led / list / menu / meter / msgbox / span / spinbox / spinner / tabview / tileview / win / **analogclock**（项目追加）

主应用通过 `lv_init()` / `lv_disp_draw_buf_init()` / `lv_disp_drv_register()` 等标准 API 使用。项目自定义字体（[main/ui/fonts/](../main/ui/fonts/)）：`font_jbmono_24/48/64/96` / `font_cjk_14` / `ui_font_NotoSanThai16`。

调用方：
- [disp_driver.c](../main/drivers/disp_driver.c)：初始化 LVGL 显示驱动、双缓冲 DMA、tick 定时器、flush 回调、触摸任务、`lvgl_lock` / `lvgl_unlock` 互斥暴露
- `main/ui/*.c`：构建所有界面
