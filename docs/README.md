# ZotLab NAS Monitor — Code Wiki

> 本 Wiki 系统性记录 ESP32-S3-Touch-LCD-3.49 项目（应用名 **ZotLab NAS Monitor**，版本 1.1.0）的架构、模块、API、依赖与运行方式，供开发者快速上手与维护参考。
>
> 目标硬件：ESP32-S3 + 3.49" 触摸 LCD（AXS15231B 控制器，物理面板 172×640 portrait，逻辑画布 640×172 landscape）。
