## 8.3 构建

在项目根目录执行：

```powershell
. "C:\esp\v5.5.4\esp-idf\export.ps1"; idf.py build
```

构建产物位于 `build/` 目录，主要文件：
- `12_HelloWorld_Skeleton.bin`：应用固件
- `12_HelloWorld_Skeleton.elf`：带调试符号的 ELF
- `bootloader/bootloader.bin`：引导加载器
- `partition_table/partition-table.bin`：分区表

### 构建选项

| 选项 | 配置位置 | 说明 |
|------|---------|------|
| `-Wno-error=stringop-truncation` | 顶层 `CMakeLists.txt` | 强制忽略字符串截断警告 |
| `EXCLUDE_COMPONENTS` | 顶层 `CMakeLists.txt` | 排除 `audio_bsp` / `codec_board` / `espressif__esp_codec_dev` |
| `BUILD_EPOCH_UTC` | `main/CMakeLists.txt` | 构建时间戳（用于 RTC 种子校正） |
| `LVGL_DMA_BUFF_LEN` | `user_config.h` | LVGL DMA 缓冲大小（默认 `172 × 128 × 2` = 44032 字节） |
| `LVGL_SPIRAM_BUFF_LEN` | `user_config.h` | PSRAM 帧缓冲大小（默认 `640 × 172 × 2` = 220160 字节） |
| `CONFIG_LV_DISP_DEF_REFR_PERIOD` | `sdkconfig` | LVGL 刷新周期（15ms ≈ 66 FPS） |
| `CONFIG_WIFI_CFG_HTTP_MAX_URI_HANDLERS` | `sdkconfig` | 必须为 64（容纳 27 esp_wifi_config handlers + ~10 webui routes） |

### sdkconfig 关键配置

通过 `idf.py menuconfig` 调整。关键项：

- `CONFIG_DEFAULT_AP_SSID` / `CONFIG_DEFAULT_AP_PASSWORD`：生产环境覆盖默认 AP 凭证
- `CONFIG_WEBUI_AUTH_USER` / `CONFIG_WEBUI_AUTH_PASSWORD`：生产环境覆盖 WebUI Basic Auth
- `CONFIG_WIFI_CFG_MAX_VARS`：esp_wifi_config 自定义变量上限（默认 10）
- `CONFIG_LV_DISP_DEF_REFR_PERIOD`：LVGL 刷新周期

## 8.5 首次启动行为

1. **NVS 初始化**：`app_cfg_init()` 调用 `nvs_flash_init()`，若失败则 `nvs_flash_erase() + nvs_flash_init()`
2. **配置加载**：`g_cfg` 从 `"cfg"` 命名空间加载（缺失字段使用默认值），`g_config` 从 `"nasmon"` 加载
3. **硬件初始化**：9 步硬件初始化，状态文本写入 Boot 屏
4. **WiFi 配网**：
   - 若 NVS 中有已存网络 → 尝试连接
   - 连接失败超过 `max_reconnect_attempts` (5) → 进入 SoftAP 配网模式（SSID `NAS-Monitor` / 密码 `12345678`）
   - 用户连接 AP 后访问 `http://192.168.4.1` 或 REST API 配网
5. **数据采集**：WiFi 连接成功后 `s_fetch_enabled = true`，`nas_event_loop` 内部定时器（原 `http_timer`）每 2 秒触发一次数据拉取
6. **UI 显示**：Boot 屏进度完成后自动跳转 Overview，开始显示 NAS 监控数据

## 8.6 CLI 调试

通过 USB-Serial-JTAG 连接后，按 Enter 进入 REPL（提示符 `esp> `）。

## 8.7 Web 配网

### 进入配网模式

1. 设备启动后，若 NVS 中无已存 WiFi 凭证或连接失败超 5 次，自动进入 SoftAP 模式
2. AP 信息：
   - SSID: `NAS-Monitor`
   - 密码: `12345678`（开发默认，生产环境通过 `CONFIG_DEFAULT_AP_PASSWORD` 覆盖）
3. 用户手机/电脑连接该 AP

### REST API

设备 IP 默认 `192.168.4.1`。所有 API 启用 Basic Auth（用户名 `admin` / 密码 `admin`，生产环境通过 `CONFIG_WEBUI_AUTH_PASSWORD` 覆盖）。

| 路径 | 方法 | 说明 |
|------|------|------|
| `/api/wifi/scan` | GET | 触发 WiFi 扫描 |
| `/api/wifi/networks` | GET | 获取扫描结果 |
| `/api/wifi/connect` | POST | 提交凭证连接网络 |
| `/api/wifi/status` | GET | 获取连接状态 |
| `/api/wifi-scan` | GET | webui 兼容路径 |
| `/api/wifi-connect` | POST | webui 兼容路径 |
| `/api/nas-settings` | GET / POST | 获取/设置 NAS 配置 |

完整 API 列表见 `esp_wifi_config` 库文档（27 个 HTTP handlers）。

### WebUI 前端

`thorrak/esp_wifi_config` 库内置 React 前端，访问 `http://192.168.4.1/` 即可使用图形界面配网。

## 8.9 常见问题排查

### 启动失败：`nvs_flash_init` 报错

**原因**：NVS 分区表版本不匹配或闪存布局变化。
**解决**：`idf.py -p COM5 erase-flash` 后重新烧录。

### WiFi 连接失败（reason=201）

**原因**：连接状态在 IP 获取前被错误报告为已连接。
**解决**：`wifi_clear` 命令清空凭证后重新配网。

### DNS 解析失败

**原因**：网络请求在 WiFi 关联后立即发起（IP 未获取）。
**解决**：等待 `EVENT_WIFI_CONNECTED` 事件后再启动数据采集（项目已通过 `s_fetch_enabled` 实现）。

### 触摸无响应

**原因**：I2C 触摸任务未启动或触摸 IC 地址错误。
**排查**：检查 `i2c_master_Init()` 是否成功，`disp_touch_dev_handle` 是否非 NULL，`EXAMPLE_PIN_NUM_TOUCH_ADDR` 是否为 `0x3b`。

### LVGL 渲染卡顿

**原因**：LVGL 任务优先级过低或被高优先级任务抢占。
**排查**：检查 `lvgl_touch` 任务优先级（应为 5，高于 LVGL 任务的 4）；确认同步 I2C 触摸读取已迁移到独立任务。

### SD 卡无法挂载

**原因**：SD 卡未格式化或文件系统不支持。
**解决**：CLI 执行 `sd_format` 格式化为 FAT。

### `app_cfg_save` 频繁写 NVS

**现状**：每次 setter 都同步全量写 NVS（30+ 字段），影响 flash 寿命与 UI 流畅度。
**规避**：滑块拖动事件只更新 `g_cfg` 内存，释放时才调 `app_cfg_save()`（项目已对部分 setter 实现，如亮度滑块）。

## 8.11 性能指标

| 指标 | 值 | 说明 |
|------|----|------|
| LVGL 刷新率 | ~66 FPS | `CONFIG_LV_DISP_DEF_REFR_PERIOD = 15ms` |
| NAS 数据拉取间隔 | 2 秒 | `nas_event_loop_timer` 默认 `s_fetch_interval_ms = 2000` |
| 心跳监控周期 | 2 秒 | `system_monitor_start()` |
| WiFi 重连次数 | 5 | `max_reconnect_attempts` |
| 重连退避 | 5s → 30s | `retry_interval_ms=5000` / `retry_max_interval_ms=30000` |
| HTTP 抓取超时 | 10 秒 | `bg_fetch_once` 的 `timeout_ms` |
| 串口超时 | 3 秒 | `SERIAL_TIMEOUT_MS` |
| LVGL DMA 缓冲 | 44 KB | 172 × 128 × 2 字节（内部 RAM） |
| LVGL PSRAM 帧缓冲 | 220 KB | 640 × 172 × 2 字节 |
