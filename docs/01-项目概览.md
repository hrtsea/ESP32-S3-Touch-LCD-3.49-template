# 1. 项目概览

## 1.1 项目定位

**ZotLab NAS Monitor** 是一款基于 ESP32-S3 与 3.49" 触摸 LCD 的 NAS 监控伴侣设备。它通过多种协议（HTTP REST / SNMP / Serial / SSH）从 Synology、QNAP、TrueNAS、Netdata、通用 Linux/Windows 主机等数据源拉取系统与存储状态，在 LCD 上以仪表盘形式实时展示 CPU/内存/磁盘/网络/风扇等关键指标，并支持 Web 配网、Wi-Fi 配置、磁盘数量配置、时区/主题/背景图等用户偏好设置。

## 1.2 功能特性

### 监控能力
- **多厂商数据源**：Synology DSM、QNAP QTS、TrueNAS、Netdata、SNMP v1、Linux Serial（UART）、Linux/Windows HTTP、Mock（测试用）
- **采集指标**：CPU% / CPU 温度 / 内存% / 磁盘% / 多盘位健康状态（OK/WARN/CRIT）/ 网络上下行速率 / 风扇 RPM / 服务列表 / 卷信息
- **多盘位支持**：SATA + M.2 槽位动态配置（合计 ≤ 16）

### 用户交互
- **触摸屏 UI**：LVGL 8.3.11，Boot 启动屏 → Overview 仪表盘 → Storage 详情 → Settings 多 Tab 设置
- **手势切换**：左右滑动切换主页 / 存储 / 设置屏，带阈值锁定
- **Web 配网**：内置 HTTP 服务器，支持 SoftAP + REST API 配网（含 Basic Auth）
- **CLI 调试**：USB-Serial-JTAG REPL，支持 wifi / mem / bl / sd_info / lang 等命令
- **多语言**：英 / 中 / 日 / 韩 四语种运行时切换
- **三套主题**：Dark / Light / High-Contrast

### 硬件能力
- **3.49" 触摸 LCD**：AXS15231B 控制器，SPI 接口，DMA 双缓冲刷新
- **PCF85063 RTC**：断电保时间，构建时间种子校正
- **QMI8658 IMU**：6 轴加速度 + 陀螺仪
- **TCA9554 IO 扩展**：电源轨控制
- **ADC 电池电压采集**：分压电路 ×3
- **音频输出**：ES8311 codec + I2S TDM，方波 MIDI 播放（《小星星》演示）
- **BOOT / PWR 按键**：基于 multi_button 状态机
- **SD 卡**：FAT 文件系统，存录音 / 背景图 / 电台列表

## 1.3 技术栈

| 层 | 技术 |
|----|------|
| 框架 | ESP-IDF v5.5.4（C/C++ 混编） |
| GUI | LVGL 8.3.11（vendored 至 components/lvgl） |
| 配网 | `thorrak/esp_wifi_config` ^0.1.0（含 React 前端） |
| LCD 驱动 | `espressif/esp_lcd_axs15231b` ^1.0.1（含内建触摸） |
| IO 扩展 | `espressif/esp_io_expander_tca9554` ^2.0.1 |
| 音频 | `espressif/esp_audio_simple_player` ^1.0.0 + `espressif/esp_codec_dev` |
| 编解码 | ES8311（DAC playback）+ ES7210（ADC record）via I2S TDM 4-slot |
| 构建 | CMake + idf.py |
| 监控 | USB-Serial-JTAG REPL（esp_console） |
| 持久化 | NVS Flash（双命名空间：`cfg` + `nasmon`） |
| 文件系统 | FAT on SD card（SPI） |
| 网络协议栈 | lwIP + esp_http_server + esp-netif |
| 时区 | POSIX TZ via `setenv("TZ")` + `tzset()`（126 城市表） |

## 1.5 配置体系总览

项目存在两套并存的配置体系，使用不同 NVS 命名空间：

| 体系 | 命名空间 | 全局实例 | 用途 |
|------|---------|---------|------|
| **app_cfg**（新） | `"cfg"` | `g_cfg` (`app_cfg_t`) | UI / 时钟 / 主题 / 背景 / 行情 / WiFi SSID 等"显示与交互层"配置，事件驱动 |
| **config**（旧） | `"nasmon"` | `g_config` (`AppConfig`) | NAS 监控业务层配置（NAS 连接 / SNMP / 风扇 / 磁盘计数 / 轮询周期） |

详见 [模块详解 § config](03-模块详解.md#config-配置层)。
